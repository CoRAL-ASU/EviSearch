Tables

A table is a schema (one definition per column) plus the papers extracted under it, their reviews and the rules learned from them.

New table from a spreadsheet

  1. A spreadsheet whose header row names the columns (hierarchical headers like Median OS | High volume | Treatment work), with one row filled in for an example paper.
  2. That example paper as a PDF, or one already in the library. It is parsed first so the agent can find each example value.
  3. The agent drafts a definition per column and asks you about anything unclear; you review and lock it.
